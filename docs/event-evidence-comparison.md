# GD-055: Event evidence comparison

The maintained story already records seven distinct events and explicit source memberships. GD-055 adds a reader projection, not a new evidence graph. The selector opens the first event with an attached publisher URL by default; visitors can select any reviewed event. The compare query parameter stores a stable event anchor for sharing and reload. Unknown anchors fall back to the default.

Three role groups list publisher reporting, institutional statements, and primary documents. A row requires an explicit event ID in the maintained record, an exact HTTPS URL without credentials, and a valid story graph. Exact duplicate URLs are grouped within each role. Cross-role overlap is included only once in the total; role counts are not additive. These are linked-record counts, not independent reporting counts. Empty means no matching link in the maintained record, not no real-world reporting. Language metadata is shown only if explicitly present. No publisher country, translation origin, event membership, syndication, or bias is inferred.

The existing Santa Ynez story is the first pilot. Its August 19 event has one linked publisher report, two institutional statement URLs and three primary document URLs. The March 13 event has two institutional statement URLs which also appear as primary documents. The source gap is shown rather than fabricating a second publisher.

This release reuses the existing shipped reviewed story and API refresh, no additional backend, database, ingestion, AI, paid service, analytics event, or source admission. It intentionally does not establish a global archive or add a new event. Historical distribution relationships are separate from comparison; integration with the reviewed distribution registry and new multilingual event records are subsequent increments. The current dataset does not establish geographic or language diversity. Tests cover exact event selection, shared URLs, unsafe URLs, integrity failure, mobile and shareable links.
